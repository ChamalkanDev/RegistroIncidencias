# Registro de Incidencias

Este proyecto es una aplicación Android para registrar incidencias o mantenimientos de equipos.

## Funciones

- Ingresar el nombre del equipo.
- Escribir una descripción.
- Registrar la información.
- Mostrar un mensaje con el estado del registro.

## Tecnologías usadas

- Kotlin
- Android Studio
- Jetpack Compose
- GitHub

## Cómo ejecutar

1. Abrir el proyecto en Android Studio.
2. Esperar que cargue Gradle.
3. Seleccionar un emulador.
4. Presionar Run.
